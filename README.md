# SAHLABU

Mizo Christian Hla Bu — offline-first Expo + TypeScript hymnbook.

Features: SQLite hymn library, Mizo Unicode, search, category filters, favorites/history, font size, lyrics/notation toggle, light/dark/sepia theme, EAS APK build.

The 10 bundled records are demo/sample lyrics, not copyrighted hymn transcriptions. Replace them with properly licensed or public-domain content.

Run: npm install && npx expo start

APK: npm install -g eas-cli && eas login && eas build --platform android --profile preview

Audio is intentionally excluded from this version.
